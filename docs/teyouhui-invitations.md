# 特友会：门户与内测注册

网站根路径 `/` 为公开产品门户，展示内容由静态虚拟数据构成，不查询车辆历史，也不使用真实车主截图。登录后的数据首页位于 `/dashboard`，其余车辆页面继续要求登录与车辆归属权限。

## 管理注册

唯一管理员进入 **系统设置 → 注册与邀请**：

- **允许新用户注册**：关闭后，`GET /register` 和 `POST /register` 均拒绝访问。门户说明暂未开放注册，已有账号仍可登录。
- **仅允许邀请注册**：与开放注册同时启用时，注册表单和服务端均要求有效邀请码。点击“保存注册设置”才应用。
- 每批可生成 **1–100** 个一次性邀请码。生成操作不会自动开放注册。
- 完整邀请码仅生成时显示，可复制全部；离开页面后不能找回。列表保留脱敏标识、生成时间、使用时间、未使用/已使用/已作废状态及分页，使用“刷新使用状态”更新统计。
- 未使用的邀请码可以作废。邀请注册关闭期间，正常注册不会消耗任何邀请码。

邀请码只用于创建普通账号，不授予管理员身份或任何车辆访问权，也不能代替车辆认领码。车辆仍通过 Tesla 授权或已有的车辆认领流程绑定。

## 服务端约束

注册策略更新、邀请码作废与公开注册使用同一个 PostgreSQL 事务锁。账号创建和邀请码核销处于同一事务，核销还检查未使用、未作废条件。缺码、伪造码、重放或错误类型均被拒绝；账号校验失败不会消耗邀请码。原有注册限流和 Cloudflare Turnstile 校验继续生效。

邀请码使用密码学随机数生成，仅存 SHA-256 摘要。日志中的 `invitation_code` 被脱敏，管理列表不返回原码或摘要。账号删除后使用时间仍保留，邀请码不会重新生效。

## 升级说明

新增迁移 `20260919090000_add_registration_invitations`：为私有账号设置增加默认关闭的邀请开关，并创建邀请码表。不修改已有账号、车辆、历史记录、密钥或当前开放注册设置。

部署前备份数据库和运行配置，运行项目既有发布迁移流程。若回退到不支持邀请码的旧应用，必须先关闭公开注册，避免旧应用忽略新的邀请开关。

门户中的界面示例直接复用首页、行程模板和充电历史组件，使用独立常量生成虚拟车辆及记录。`/preview/home`、`/preview/trips`、`/preview/charging` 不运行会话或数据库管道，不挂载 LiveView，也不加载应用脚本或地图服务。示例可以放大，跟随门户明暗模式，窄屏下使用真实移动端布局。充电实时采样区域不包含在历史记录示例中。
